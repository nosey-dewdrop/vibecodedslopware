# vibecodedflopware

*leetcode, but every question comes from your own codebase.*

### live: https://damlahelloworld.github.io/vibecodedflopware/

## what is this?
a lot of us shipped an app we can no longer edit by hand. vibecodedflopware turns your own repo into a practice ground: it maps your codebase and quizzes you on it — reading, fill-the-blank, bug injection, architecture — until you actually own what you shipped.

## features
- questions generated from your code, not a question bank
- reading, fill-the-blank, bug injection and architecture drills
- mastery tracked per module of your app
- zero code retention: your code is not stored

## technologies
- TypeScript
- static landing on GitHub Pages

## where this is going
the landing is live and the product is being built. next: connect-a-repo flow and the first drill types.
