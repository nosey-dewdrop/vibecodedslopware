01 / the problem

you shipped an app you can't edit

ai wrote it. it works. it's live. and you couldn't change a single line of it without breaking three others. that's not owning software — that's renting it from a chatbot.

"i can't touch one line of my own app without claude."
— every vibecoder, eventually

02 / how it works

your repo becomes your curriculum

  1. + connect a repo. your browser fetches it directly from github. the code never touches our servers.
  2. ✱ get the map. files, classes, functions, who calls whom — extracted right on your machine.
  3. ▪ get quizzed. questions generated from your actual lines. not fizzbuzz. your buzz.
  4. + reach mastery. module by module, until "i can't touch this file" becomes "i wrote this file, basically."

03 / question types

four ways to own your code

  • + code reading — "what does this function return for input x?"
  • + fill the blank — a real line of yours, one piece missing.
  • + bug injection — we break one line of your code. find it.
  • + architecture — "to add feature x, which file do you touch?"

04 / privacy

snapchat, but for tech

your code is never stored. not in a database, not in a log, not in a backup. ever.

  • analysis runs in your browser, the map is built on your machine
  • your questions live on your device, not on our servers
  • we only keep numbers: mastery %, streaks, solved counts

if someone hacked us, they'd steal your high score.
